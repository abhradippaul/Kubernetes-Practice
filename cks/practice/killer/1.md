## Task 4 — Stream Multiplex Deployment

**Node:** `ssh cks5608`

Edit `/opt/course/4/stream-multiplex.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: stream-multiplex
spec:
  replicas: 1
  selector:
    matchLabels:
      app: stream-multiplex
  template:
    metadata:
      labels:
        app: stream-multiplex
      annotations:
        token-lifetime: "1200" # annotation required
    spec:
      serviceAccountName: stream-multiplex # use this SA
      automountServiceAccountToken: false # disable automounting
      containers:
        - name: <container-name>
          image: <image>
          volumeMounts:
            - name: token-vol
              mountPath: /var/run/secrets/custom/ # custom mount path
      volumes:
        - name: token-vol
          projected:
            sources:
              - serviceAccountToken:
                  path: token
                  expirationSeconds: 1200 # expiration 1200s
```

```bash
kubectl apply -f /opt/course/4/stream-multiplex.yaml
kubectl get pods -l app=stream-multiplex
```

## Task 6 — Immutable Deployment

**Node:** `ssh cks2546`

Modify `/opt/course/6/immutable-deployment.yaml` — add `readOnlyRootFilesystem: true` and an `emptyDir` for `/tmp`:

```yaml
spec:
  containers:
    - name: <container-name>
      image: <image>
      securityContext:
        readOnlyRootFilesystem: true # make root FS immutable
      volumeMounts:
        - name: tmp-vol
          mountPath: /tmp # only /tmp is writable
  volumes:
    - name: tmp-vol
      emptyDir: {}
```

```bash

# edit the new file as above
kubectl apply -f /opt/course/6/immutable-deployment-new.yaml
```

```bash
  -p '{"stringData":{"password":"4c!29f_Ee2e"}}'
```


### Move Secret `user-data` to another namespace

```bash
# Export the secret (strip namespace/metadata fields)
kubectl -n team-khaki-us-east-ad1 get secret user-data -o yaml \
  | sed 's/namespace: team-khaki-us-east-ad1/namespace: team-khaki-us-east-ad2/' \
  | kubectl apply -f -

# Delete from source namespace
kubectl -n team-khaki-us-east-ad1 delete secret user-data
```

### Convert ConfigMap `app-data` to a Secret

```bash
# Get configmap data
kubectl -n team-khaki-us-east-ad1 get configmap app-data -o yaml

# Create a secret with the same key/values
kubectl -n team-khaki-us-east-ad1 create secret generic app-data \
  --from-literal=<key>=<value>   # use actual keys from the configmap

# Update Pods/Deployments to reference the secret instead of the configmap
# Then delete the configmap
kubectl -n team-khaki-us-east-ad1 delete configmap app-data
```

## Task 11 — ImagePolicyWebhook

**Node:** `ssh cks4024`

### Create AdmissionConfiguration

```bash
cat <<EOF > /opt/course/12/webhook/admission-config.yaml
apiVersion: apiserver.config.k8s.io/v1
kind: AdmissionConfiguration
plugins:
  - name: ImagePolicyWebhook
    configuration:
      imagePolicy:
        kubeConfigFile: /etc/kubernetes/webhook/webhook.yaml
        allowTTL: 10
        denyTTL: 10
        retryBackoff: 20
        defaultAllow: true
EOF
```

### Update kube-apiserver manifest

```bash
sudo vi /etc/kubernetes/manifests/kube-apiserver.yaml
```

Add/modify these sections:

```yaml
spec:
  containers:
    - command:
        - kube-apiserver
        # Add these flags:
        - --admission-control-config-file=/etc/kubernetes/webhook/admission-config.yaml
        - --enable-admission-plugins=...,ImagePolicyWebhook
      volumeMounts:
        - name: webhook
          mountPath: /etc/kubernetes/webhook
          readOnly: true
  volumes:
    - name: webhook
      hostPath:
        path: /opt/course/12/webhook
        type: DirectoryOrCreate
```

## Task 12 — CiliumNetworkPolicy

**Node:** `ssh cks8930`

```yaml
apiVersion: "cilium.io/v2"
kind: CiliumNetworkPolicy
metadata:
  name: default
  namespace: metadata-access
spec:
  endpointSelector:
    matchLabels: {}

  egress:
    # 1. Allow egress to 0.0.0.0/0
    - toCIDR:
        - 0.0.0.0/0

    # 2. Allow egress to Endpoints in the same Namespace
    - toEndpoints:
        - {}

    # 3. Allow egress to Endpoints in the kube-system Namespace
    - toEndpoints:
        - matchLabels:
            io.kubernetes.pod.namespace: kube-system

  egressDeny:
    # 4. Deny egress to 192.168.100.21 on port 9055
    - toCIDR:
        - 192.168.100.21/32
      toPorts:
        - ports:
            - port: "9055"
              protocol: TCP
```

> **Note:** For a Deny rule in Cilium, use `toCIDR` allow for everything EXCEPT the restricted IP, or use Cilium's CIDR deny if available in your version:

```bash
kubectl apply -f cilium-netpol.yaml
```

## Task 15 — Falco Custom Rules

**Node:** `ssh cks5608`

Append to `/etc/falco/falco_rules.local.yaml`:

```yaml
- rule: Custom Rule 1
  desc: Detect container access to /etc/kubernetes path on host
  condition: open_read and fd.name startswith /etc/kubernetes
  output: "custom_rule_1 file=%fd.name container=%container.id"
  priority: WARNING

- rule: Custom Rule 2
  desc: Detect processes performing kill syscalls
  condition: evt.type=kill
  output: "custom_rule_2 event_signal=%evt.arg.sig event_pid=%evt.arg.pid container=%container.id"
  priority: INFO
```

Run Falco and capture logs:

```bash
sudo falco -r /etc/falco/falco_rules.local.yaml 2>&1 | timeout 30 tee /opt/course/16/logs
# OR
sudo falco --duration 30 > /opt/course/16/logs 2>&1
```

## Task 16 — Audit Logging

**Node:** `ssh cks3477`

### Reduce log backups to 1

Edit the kube-apiserver manifest:

```bash
sudo vi /etc/kubernetes/manifests/kube-apiserver.yaml
# Change:
# --audit-log-maxbackup=<current> -> --audit-log-maxbackup=1
```

### Update Audit Policy `/etc/kubernetes/audit/policy.yaml`

```yaml
apiVersion: audit.k8s.io/v1
kind: Policy
rules:
  # Log Secrets at Metadata level
  - level: Metadata
    resources:
      - group: ""
        resources: ["secrets"]

  # Log system:nodes group at RequestResponse level
  - level: RequestResponse
    userGroups: ["system:nodes"]

  # Default: don't log anything else
  - level: None
```

### Apply changes and clear old logs

```bash
# The apiserver will reload the policy automatically after manifest edit
# Clear the audit log
echo > /etc/kubernetes/audit/logs/audit.log
```
